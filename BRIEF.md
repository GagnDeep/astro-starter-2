# Institute of Catering - Brief

**Domain**: instituteofcatering.com
**Business**: A practical operator resource for people who RUN catering businesses (licensing, pricing, contracts, software and certifications).
**Target Buyer**: Catering business owners, not students.
**Monetization**: Referrals to catering software and affiliate commissions for certifications.
**Positioning Constraints**:
- This is deliberately NOT a cooking school. Accredited colleges own the education SERP, so never target course, diploma, or qualification intent.
- The site must clearly state that it does not teach or accredit.
