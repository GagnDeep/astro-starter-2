# jsonmock Brief

## The Domain and Business
jsonmock is a deterministic record-and-replay mocking solution for LLM and AI-agent API responses in CI environments.

## The Buyer
Engineering teams who are currently burning real API credits in CI or hand-rolling brittle JSON fixtures for LLM interactions.

## Monetization
Developer SaaS subscription.

## Positioning Constraints
- Generic mock-API is a dead commodity space with a $5/month price ceiling.
- Every single page must specifically focus on the **LLM and agent testing wedge**.
- Real, runnable code examples must be used instead of marketing abstractions.
