# Brief
**Domain:** jsonmock.com
**Business:** Deterministic record-and-replay mocking of LLM and AI-agent API responses for CI.
**Buyer:** Engineering teams currently burning real API credits in CI or hand-rolling brittle JSON fixtures.
**Monetization:** Developer SaaS subscription.
**Positioning constraints:** Generic mock-API is a dead commodity space with a $5/month price ceiling. Every page must be about the LLM and agent testing wedge specifically, with real, runnable code examples rather than marketing abstractions.
