## 5-7 Competitor Teardowns

### 1. Google Drive Embed
- **Homepage Block Order:** Hero (Sign in) -> Features -> Pricing (N/A) -> Enterprise -> Footer.
- **Gaps:** Requires Google account for host, heavy tracking, often blocked by enterprise firewalls, limited customization, clunky UI on mobile, forces Google branding.

### 2. PDF.js (Mozilla)
- **Homepage Block Order:** Hero -> Demo -> Code snippet -> Features -> Footer.
- **Gaps:** Developer-only tool, requires significant coding to implement basic UI, no built-in analytics, hard to style, overkill for simple embeds.

### 3. Scribd / SlideShare
- **Homepage Block Order:** Hero (Search) -> Trending docs -> Categories -> Premium upsell -> Footer.
- **Gaps:** Forces users into their ecosystem, heavily ad-supported, pushes downloads and subscriptions, terrible for professional brand embedding.

### 4. Issuu
- **Homepage Block Order:** Hero -> Trusted by -> Features -> Use Cases -> Pricing -> Footer.
- **Gaps:** Magazine-focused, flipbook style isn't right for standard documents, very expensive for unbranded embedding, heavy JS payload.

### 5. DocumentCloud
- **Homepage Block Order:** Hero -> About -> Latest Docs -> API -> Footer.
- **Gaps:** Journalism-focused, requires approval to use, not built for general-purpose embedding, rigid UI.

### 6. Box Embed
- **Homepage Block Order:** Hero -> Enterprise features -> Security -> Integrations -> Footer.
- **Gaps:** Requires Box enterprise account, complex setup, heavy iframes, tailored for internal collaboration rather than public website display.

### 7. Adobe PDF Embed API
- **Homepage Block Order:** Hero -> Developer benefits -> Code examples -> Pricing -> Footer.
- **Gaps:** Requires Adobe API key, complex telemetry, heavy script (often blocked by ad blockers), limited non-PDF support.
