# PLAN - uconvertdocument.com

## Positioning & Strategy
**Positioning:** Free online document format converter tool monetized with ads. Fast, secure, and no installation required.
**Rejected Positioning:**
1. Paid subscription model.
2. Desktop application.
3. API-only service.
4. Niche converter for only one format (e.g., only CAD).
**Voice:** Helpful, clear, professional, concise.
**Banned words:** "innovative", "synergy", "disruptive", "click here", "read more".

## Competitor Teardowns (5-7)
1. **iLovePDF**: Homepage focuses on tool grid. Strong on PDF manipulation. Gap: Lacks deep educational content on formats.
2. **Smallpdf**: Very clean, colorful UI. Homepage highlights top tools and trust signals. Gap: Aggressive paywalls.
3. **Zamzar**: Huge format support. Homepage is a single multi-step form. Gap: UI feels outdated, ads are intrusive.
4. **CloudConvert**: Developer-focused, clean, advanced options. Gap: Complex for casual users.
5. **Adobe Acrobat Online**: High trust, but requires sign-in for many actions. Gap: Slow workflow.
6. **FreeConvert**: Good format support, clear file size limits. Gap: Cluttered interface.
7. **PDF2Go**: Good toolset, visually busy. Gap: Navigation is overwhelming.

## Homepage Block Order (Unique)
1. **Hero**: Main conversion form (smart detect, drag and drop).
2. **Value Prop**: 3 clear points (Free, Secure, Fast).
3. **Popular Tools Carousel**: Direct links to top converters (Word to PDF, etc.).
4. **Format Matcher**: Interactive block "I have X, I need Y" dropdowns.
5. **How It Works**: 3 simple steps (Upload, Convert, Download).
6. **Trust Signals**: Real-time stats (Files converted today).
7. **Educational Snippets**: Links to latest guides.
8. **FAQ**: Quick answers.
9. **Capture**: Newsletter for tips.
