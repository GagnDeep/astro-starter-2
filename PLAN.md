## Competitor Teardowns
1. **MasterTheHandpan.com**
   - *Blocks*: Hero (Courses) -> Social Proof -> Value Prop -> Course Grid -> Instructor Bio -> Testimonials -> Footer.
   - *Gaps*: Very course-focused. Lacks deep tool calculators (e.g. scale matcher). No coverage of cheap alternatives.
2. **HandpanMaker.com (fictionalized/general maker)**
   - *Blocks*: Hero (Video) -> Current Batch -> Waitlist -> FAQ -> Footer.
   - *Gaps*: Zero beginner education. Intimidating for entry-level buyers.
3. **PlanetHandpan.com**
   - *Blocks*: Hero -> Featured Handpans -> Blog -> About -> Footer.
   - *Gaps*: Weak on technical comparisons between scales. Affiliate content is thin.
4. **HangDrumSandbox.com**
   - *Blocks*: Hero -> Virtual Player -> Shop -> Footer.
   - *Gaps*: Very dated design. Virtual player is Flash/Canvas, not accessible.
5. **TongueDrumInsights.com**
   - *Blocks*: Hero -> Best of Guides -> Review Grid -> Footer.
   - *Gaps*: Article-heavy, no interactive tools, lacks visual contrast.

   - *Blocks*: Hero -> Events -> Directory -> Footer.
   - *Gaps*: Focused on community events, not buyer intent.

## Positioning
**Chosen:** The pragmatic, budget-conscious guide to handpans and their cheaper alternatives (steel tongue drums), focusing on practical buying advice, maintenance, and music theory without the mystical fluff.
**Rejected 1:** High-end boutique handpan reviewer (too saturated, hard to monetize without direct maker relationships).
**Rejected 2:** Spiritual/meditation focused handpan site (banned mystical fluff).
**Rejected 3:** Purely theoretical acoustics blog (too academic, poor affiliate fit).
**Rejected 4:** Sheet music repository (too hard to scale without copyright issues).

## Voice & Tone
- **Voice:** Direct, practical, empirical, slightly skeptical of industry myths.
- **Banned Words:** Mystical, magical, spiritual, healing, vibrations (in a non-acoustic sense), vibes, energy, sacred, ancient (the instrument was invented in 2000).
