# PLAN.md

## Positioning
**Target Audience:** California homeowners considering solar installation, specifically navigating NEM 3.0, high utility rates (PG&E, SCE, SDG&E), and battery storage requirements.
**Voice:** Authoritative, transparent, slightly irreverent but strictly factual/serious on tax dates, numerical calculations, warnings, and legal disclaimers. Avoid typical solar sales jargon ("free solar", "zero down").
**Positioning:** Data-driven, unbiased California solar resource. "We do the math, you make the choice."

**Rejected Positioning (+4):**
1. Aggressive lead-gen broker ("Get 3 quotes now!")
2. Environmental activist ("Save the planet with panels")
3. Cheap solar provider ("Lowest price per watt guaranteed")
4. Government grant aggregator ("Claim your free government panels")

## Competitor Teardown
1. **EnergySage**: Tools win over articles. Gap: Too national, lacks specific CA utility rate nuances. Homepage block order: Hero -> How it works -> Reviews -> Calculator -> Articles.
2. **SolarReviews**: Heavy on reviews. Gap: Hard to find unbiased technical data without giving an email. Homepage block order: Hero (Lead capture) -> Brands -> Reviews -> State guides.
3. **NerdWallet Solar**: Financial focus. Gap: Lacks technical depth and specific installer insights. Homepage block order: Hero -> Articles -> Calculator -> Compare.
4. **Sunrun (Direct Installer)**: Sales focus. Gap: Biased, pushes leasing. Homepage block order: Hero -> Benefits -> Products -> Testimonials -> Contact.
5. **Local CA Installer (e.g., Baker Electric)**: Regional. Gap: Weak educational content. Homepage block order: Hero -> Services -> About us -> Awards -> Blog.

**Our Homepage Block Order (Unique):**
1. Hero: Data-backed statement on CA solar savings with immediate tool access (Calculator).
2. The NEM 3.0 Reality Check: Transparent breakdown of the current state of CA solar.
3. Interactive Maps/Data: Real-time utility rate tracker (PG&E, SCE, SDG&E).
4. Reference Library Highlight: Deep dive into battery tech and panel specs.
5. Capture Form: Newsletter for CA rate updates.
