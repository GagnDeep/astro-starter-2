# PLAN.md

## Research & Audience

Target audience: Users who need to quickly convert document formats (PDF, DOCX, XLSX, etc.) online for free, usually for school, work, or personal admin.
Verbatim phrases:

- "how to convert pdf to word free"
- "convert doc to pdf without losing formatting"
- "make pdf editable"
- "free online pdf converter no watermark"
- "extract text from image"
- "convert jpg to pdf"
- "compress pdf to 100kb"
- "merge pdf files free"
- "split pdf into pages"
- "convert epub to mobi"
- "convert mobi to epub"
- "convert word to jpg"
- "unlock pdf file"
- "protect pdf with password"
- "convert excel to pdf"
- "convert powerpoint to pdf"
- "convert pdf to excel"
- "convert pdf to powerpoint"
- "convert html to pdf"
- "convert pdf to html"

Jargon they never use: "lossless compression algorithm", "OCR vectorization", "hex stream manipulation".

Competitors:

1. Zamzar: Hero with upload -> formats grid -> SEO text -> footer. Freemium. Voice is utility. Gap: pages are very thin on instructions.
2. CloudConvert: Hero upload -> options -> features -> footer. Freemium. Voice is technical. Gap: confusing pricing.
3. Smallpdf: Hero -> tools grid -> features -> footer. Paid heavy. Voice is friendly. Gap: very aggressive paywall.
4. iLovePDF: Hero tools grid -> features -> footer. Freemium. Voice is simple. Gap: clunky design on some tools.
5. FreeConvert: Hero -> settings -> features -> footer. Ad-heavy. Voice is chaotic. Gap: poor user experience.

Keywords by Intent:

- Transactional (Tools): pdf to word, word to pdf, merge pdf, split pdf, compress pdf, jpg to pdf, pdf to jpg, excel to pdf, pdf to excel, ppt to pdf.
- Informational (Articles): how to edit a pdf, why is my pdf so large, what is an epub file, docx vs doc, difference between jpg and png.
- Navigational: smallpdf alternative, zamzar alternative.

Positioning:
"The fastest, completely free document converter. No limits, no watermarks, no signups."
Rejected alternatives:

- "AI-powered document conversion" (buzzwordy)
- "Enterprise document management" (wrong audience)
- "The cheapest PDF tool" (we are free)
- "Your document suite" (too broad)

Voice Rules:
Direct, clear, helpful. Banned words: "leverage", "synergy", "utilize", "revolutionary", "disruptive".
