## Competitor Teardowns
1. **Vimeo**
   - Order: Hero (Trust/Brands) -> Features -> Use Cases -> Testimonials -> Pricing
   - Gaps: Complex pricing, bloated player, pivot away from small creators.
2. **Wistia**
   - Order: Hero -> Interactive Demo -> Features (Marketing focus) -> Integrations -> Footer
   - Gaps: Very expensive, heavily enterprise/B2B focused, overkill for solopreneurs.
3. **Bunny.net (Stream)**
   - Order: Hero (Speed/Cost) -> Tech Specs -> Cost Calculator -> API Docs -> CTA
   - Gaps: Too technical, lacks a simple drop-in UI for non-devs.
4. **Mux**
   - Order: Hero (API focus) -> Dev Experience -> Performance -> Case Studies
   - Gaps: Pure API, no out-of-the-box embeddable player for creators.
5. **YouTube (Unlisted embeds)**
   - Gaps: Leaks traffic, shows ads/related videos, branding cannot be removed.

## Positioning
**Chosen Positioning:** The simplest, fastest, ad-free video player built for independent creators and their own websites.
**Rejected Positioning:**
1. Enterprise video marketing platform (too complex/crowded).
2. Video API for developers (Mux/Bunny do this better).
3. Social video network (not embedding).
4. Live streaming platform (VOD focus only).

## Voice & Tone

- **Banned words:** Synergy, revolutionary, disrupt, leverage, next-gen, holistic.
