   - Block order: Hero with converter, How it works, Formats supported, Testimonials, Footer.
   - Gaps: No in-browser playback, slow queues, aggressive upsell.
2. **CloudConvert**
   - Block order: Hero with converter, Options panel, Features, API docs, Footer.
   - Gaps: Intimidating for non-technical users, no player, pricing is complex.
3. **FreeConvert**
   - Block order: Hero with converter, Ad block, Advanced settings, FAQ, Footer.
   - Gaps: Heavy ads, confusing UI, generic results.
4. **VEED**
   - Block order: Hero with video editor, Social proof, Features, Templates, Footer.
   - Gaps: Too heavy for simple conversions, requires signup for basic features.
5. **Online-Convert**
   - Block order: Grid of converters, Hero with converter, Ad block, Features, Footer.
   - Gaps: Dated UI, intrusive ads, poor mobile experience.

   - Block order: Hero with download, Features, Documentation, Footer.
   - Gaps: Not online, steep learning curve.
