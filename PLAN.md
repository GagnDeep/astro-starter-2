# PLAN: TrackAndLog.com

## Positioning
**Core:** A fast, lightweight, and uncompromising metric tracking tool for personal quantified-self logging.
**Rejected positioning:**
1. A bloated "life OS" that requires hours of setup.
2. A generic B2B analytics dashboard.
3. A motivational/gamified habit builder with streaks and confetti.
4. A heavily social sharing-focused progress tracker.

## Competitor Teardowns (5-7)
1. **Strides**
   - *Homepage:* Hero (app store links) -> Features grid -> Testimonials -> Pricing.
   - *Gaps:* Very iOS-centric, locks data, no lightweight web app. Overly complex setup.
2. **Habitica**
   - *Homepage:* Hero (pixel art) -> Gamification features -> Community -> Platforms.
   - *Gaps:* Gamification is highly distracting for serious metric trackers. Not good for pure numerical data (e.g. weight, blood pressure).
3. **Loop Habit Tracker**
   - *Homepage:* Hero -> Open source features -> Download.
   - *Gaps:* Android only, not web-first, lacks continuous metric tracking (mostly binary habits).
4. **Nomie (Historical/Forks)**
   - *Homepage:* Hero -> Local first pitch -> Feature list.
   - *Gaps:* Complex to self-host, UI can be dense, discontinued official support.
5. **Exist.io**
   - *Homepage:* Hero -> Integrations grid -> Correlate everything -> Pricing.
   - *Gaps:* Heavy reliance on passive integrations, overkill for manual loggers, subscription fatigue.
6. **Everyday**
   - *Homepage:* Hero -> Board view -> Multi-device -> Testimonials.
   - *Gaps:* Strictly "do it every day" streaks, not built for metrics or measurements.
7. **Apple Health / Google Fit**
   - *Homepage:* Landing pages focus on hardware ecosystem.
   - *Gaps:* Siloed into OS ecosystem, terrible for custom metrics (e.g., "pages read", "cups of coffee").
