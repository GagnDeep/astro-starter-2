# PLAN.md

## Positioning
**aerospaceuae.com** is the definitive, no-nonsense B2B directory and news portal for UAE aerospace and defense suppliers.
We connect global tier-1s, local manufacturers, and defense procurement officers. We do not do fluff, PR speak, or generalized global news. If it doesn't impact the UAE aerospace and defense supply chain, we don't cover it.

### Rejected Alternatives
1. *A global defense news site:* Too broad, competes with Defense News.
2. *A purely technical engineering forum:* Misses the procurement and B2B connection.
3. *A government-style PR magazine:* Lacks the hard data and vendor directory.
4. *A generic MENA business directory:* Not specialized enough for AS9100/defense requirements.

## Competitor Teardown
1. **Arabian Aerospace**: Magazine format. *Gap:* Hard to find specific suppliers, poor directory, slow news cycle. *Block order:* Hero -> Ads -> Latest News.
2. **Defense News (ME section)**: Global focus. *Gap:* No B2B directory, only covers massive billion-dollar contracts. *Block order:* Hero -> Trending -> Region.
3. **Jane's**: Paywalled intelligence. *Gap:* Too expensive for basic supplier discovery, not a local marketing channel. *Block order:* Hero -> Paywall prompt -> News.
4. **Zawya (A&D category)**: Generic business news. *Gap:* Misses the technical defense certifications and specific aerospace verticals. *Block order:* Market data -> Top stories -> Press releases.
5. **Nation Shield**: Official UAE journal. *Gap:* Focuses on military strategy and official visits, not B2B supply chain matching. *Block order:* Official news -> Interviews -> Features.

Our block order will be: Hero (Search Directory) -> Featured UAE Suppliers -> Offset Program Updates -> Recent B2B News -> Procurement Tools -> Newsletter Capture.

## Voice Rules
- **Tone:** Authoritative, direct, technical, objective.
- **Banned Words:** Revolutionary, game-changing, synergistic, disruptive, holistic, cutting-edge, state-of-the-art.
- **Rule:** Cite sources for figures. Use exact specifications (e.g., "AS9100D", not "high quality").
