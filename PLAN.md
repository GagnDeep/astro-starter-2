# PLAN: ClearPath Finance

## Positioning
**Chosen:** ClearPath Finance - Actionable, tool-driven financial planning for independent professionals and self-directed investors.
**Rejected:**
1. Institute of Financial Planning (Collision with real entity).
2. Wealth Tools Co (Too generic, sounds like a SaaS).
3. The Finance Hub (Overused, lacks authority).
4. Pro Financial Planning (Too corporate, implies advising rather than tools).

## Voice & Tone
- **Voice:** Direct, evidence-based, pragmatic, authoritative.
- **Banned Words:** "Journey", "Synergy", "Unlock", "Hustle", "Revolutionize", "Next-level".

## Competitor Teardowns (5)
1. **NerdWallet:** Hero -> Credit Cards -> Mortgages -> Investing -> Articles. *Gap:* Too generic, heavily incentivized by affiliate links, tools are often buried or clunky.
2. **Investopedia:** Hero -> Search -> Popular Terms -> Recent Articles. *Gap:* Encyclopedia model, lacks integrated actionable tools, very ad-heavy.
3. **SmartAsset:** Hero -> Find an Advisor -> Calculators -> Articles. *Gap:* Lead gen for advisors, tools are a funnel rather than the end product.
4. **Bankrate:** Hero -> Rates (Mortgage, CD, Savings) -> Calculators -> News. *Gap:* Rate-focused, less about comprehensive planning, cluttered UI.
5. **The Penny Hoarder:** Hero -> Latest Posts -> Categories -> Newsletter. *Gap:* Focuses on frugal living and side hustles, lacks deep financial planning tools.
