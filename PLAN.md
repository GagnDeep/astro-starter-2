## 5-7 Named Competitor Teardowns

### 1. DataCamp
- **Homepage Block Order:** Hero (Sign up) -> Logo farm -> Value props -> Course categories -> Testimonials -> CTA.
- **Gaps:** Heavily focused on data science and coding, lacking pure "no-code AI workflow" focus. High barrier to entry for non-technical users.

### 2. Coursera (AI For Everyone / DeepLearning.AI)
- **Homepage Block Order:** Hero (Search) -> Partner logos -> Degrees -> Certifications -> Testimonials -> Footer.
- **Gaps:** Theoretical, academic, long-winded. Doesn't move at the speed of the current AI ecosystem. Missing practical, day-to-day tool application.

### 3. Udacity
- **Homepage Block Order:** Hero -> Enterprise CTA -> Nanodegree programs -> Advantage -> Outcomes -> CTA.
- **Gaps:** Very expensive, heavily focused on enterprise, rigid structure. Takes months to complete.

### 4. Udemy (Various AI Courses)
- **Homepage Block Order:** Hero (Promo) -> Top categories -> Featured courses -> Instructor CTA -> Footer.
- **Gaps:** Variable quality, often outdated within weeks, lacking a unified curriculum or practical hands-on sandboxes.

### 5. AIHR (AI in HR specifically, but analogous to niche platforms)
- **Homepage Block Order:** Hero -> Trust indicators -> Value prop -> Curriculum -> Pricing -> Footer.
- **Gaps:** Too niche. Doesn't cater to a broader audience wanting general practical AI skills.

### 6. Section (Section School)
- **Homepage Block Order:** Hero -> Logos -> Workshops -> Instructors -> Testimonials -> Membership CTA.
- **Gaps:** Expensive membership model, focused on live cohort-based learning which doesn't scale for self-paced learners.

## Positioning
**Chosen Positioning:** The pragmatic, up-to-date AI skills platform for working professionals. We teach you how to use AI to do your job better, faster, and without needing a PhD in computer science.

**Rejected Positioning:**
1. *The Academic AI Institute:* Too theoretical, slow to update.
2. *The AI Hustle Bro Community:* Too scammy, lacks rigor and trust.
3. *The Enterprise AI Transformation Consultancy:* Too expensive, ignores the individual contributor.
4. *The Deep Learning Code Bootcamp:* Too technical, alienates the 90% of workers who don't code.

## Voice and Banned Words
**Voice:** Clear, authoritative, pragmatic, jargon-free, encouraging.
**Banned Words:** "Revolutionary", "Magic", "Unleash", "Hack", "10x", "Skyrocket", "Guru", "Ninja".
