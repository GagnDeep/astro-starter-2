## Competitor Teardown
1. **TurboTax:**
   - *Blocks:* Hero -> "Free" claim -> Pricing cards -> Testimonials -> FAQ.
   - *Pricing:* Heavily upsells. "Free Edition" is very limited.
   - *Tone:* Overly friendly, reassuring, gamified.
   - *Gap:* Lack of transparency on what exactly kicks you out of "Free".
2. **H&R Block:**
   - *Blocks:* Hero -> Options (Online vs In-person) -> Features -> Upgrades.
   - *Pricing:* Similar to TurboTax, slightly cheaper base upgrades.
   - *Tone:* Professional, established, safe.
   - *Gap:* Confusing interface between software and human help.
3. **FreeTaxUSA:**
   - *Blocks:* Hero -> Federal Free -> State Pricing -> Features.
   - *Pricing:* Free federal for everyone, $15 state.
   - *Tone:* No-nonsense, slightly dated, honest.
   - *Gap:* UI feels old, lacks deep educational content for complex edge cases.
4. **TaxSlayer:**
   - *Blocks:* Hero -> Pricing cards -> Feature comparison -> Reviews.
   - *Pricing:* "Simply Free" is very restricted.
   - *Tone:* Value-focused, energetic.
   - *Gap:* Customer support is lacking in free tiers.
5. **NerdWallet (Tax Hub):**
   - *Blocks:* Hero -> Best Software list -> Calculators -> Articles.
   - *Pricing:* Affiliate model.
   - *Tone:* Objective, authoritative, financial advisor.
   - *Gap:* Overwhelming walls of text, tools aren't deeply integrated.
6. **Cash App Taxes:**
   - *Blocks:* Hero -> "100% Free" claim -> Mobile app push -> Features.
   - *Pricing:* Completely free including state, but requires mobile app.
   - *Tone:* Casual, mobile-first, Gen-Z focused.
   - *Gap:* Desktop experience is secondary, missing advanced tax forms.

## Positioning & Voice
**Positioning:** The brutally honest, no-B.S. guide to not paying to file your taxes. We tell you exactly when software is actually free, when they will bait-and-switch you, and how to do it yourself if needed.
**Rejected Alternatives:**
1. The "Cheerleader" (TurboTax style, too fake).
2. The "Financial Advisor" (NerdWallet style, too dry).
3. The "Anti-Tax Activist" (Too political).
4. The "Pure Affiliate" (Just ranking software for money, lacks trust).

**Voice Rules:**
- Direct, transparent, slightly skeptical of corporate claims.
- Banned words: "Revolutionary", "Hassle-free", "Tax-time fun", "Maximum refund guaranteed" (unless critiquing it), "Synergy".
