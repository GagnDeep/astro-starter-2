# FreeTaxPDF.com

A seasonal hub for downloadable free tax form PDFs with tax software affiliate links.

## Features implemented
- Fully statically generated Astro site.
- Built-in `capture` API for leads (Newsletter & Contact).
- Zod-schema powered content collections.
- Strict SEO rules with JSON-LD headers.
- Plain HTML forms with progressive enhancement.
- No-JS fallbacks on interactive tax calculators.

## Development

```bash
pnpm install
pnpm dev
pnpm build
```

See `AGENTS.md` and `CLAUDE.md` for specific architectural guidelines.
