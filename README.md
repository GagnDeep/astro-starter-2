# uDocumentView

The fastest, safest way to view any document in your browser—no downloads, no accounts, no trace left behind.

## Features

- **Zero-Footprint Viewer**: Parses documents locally in the browser when possible. No logs, no caching.
- **Tools Collection**: PDF, DOCX, XLSX, PPTX, CSV, RTF, TXT, ODT, EPUB, MOBI viewers online without accounts.
- **Calculators**: Print Cost, File Size, Read Time calculators tailored to document workflows.
- **Reference Library**: Explanations on document formats, metadata, security, parsing.
- **SEO Ready**: JSON-LD, OpenGraph tags correctly formatted via Astro build.
- **RUM / Observability**: OpenObserve metrics loaded into the front-end securely.
