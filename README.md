# UViewDocument

A simple online document viewer for shared files. Focuses on speed, privacy, and ease of use.

## Project Structure
- `src/pages/` — Main site pages, Reference Library (15+ pages), Formats Taxonomy (10+ pages), Glossary (25+ pages).
- `src/content/blog/` — Blog posts (12+ posts covering intent keywords).
- `src/components/tools/` — 3 calculators (File size transfer, Storage capacity, Aspect ratio).
- Form Capture is handled by exact conventions in `AGENTS.md`.

## Scripts
- `pnpm install`
- `pnpm dev`
- `pnpm build`

Built with Astro + Tailwind v4 + CloudCannon templates.
