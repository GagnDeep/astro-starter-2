# Digestine

A comprehensive digestive-health supplement brand built with Astro, Tailwind, and a headless capture API.

## Project Structure
- Astro 6 framework
- Zero-client JS by default (islands architecture)
- Form capture via `api.markremover.com`

## Installation
```bash
pnpm install
```

## Development
```bash
pnpm dev
```

## Build & Assets
```bash
pnpm build
pnpm assets
pnpm check
```
