# uViewPDF

The fastest, frictionless way to read and markup PDFs online without creating an account.

## Features

- Instant PDF annotation: Highlight, draw, and add text.
- Privacy-focused: No login required, processing is local.
- Built with Astro and Tailwind CSS.
- Zero client JS by default, fast islands architecture.
- Full reference library and guides.

## Setup

```bash
pnpm install
cp .env.example .env
pnpm dev
```
