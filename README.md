# FoodLogTrack

Simple food log web app monetized with ads and diet affiliate products.

## Structure
- **Content:** src/content/pages and src/content/blog (includes 15 library pages, 10 taxonomy, 1 glossary, 12 blog posts).
- **Tools:** src/pages/tools (BMR, TDEE, Macro calculators).
- **Compare:** src/pages/compare (MyFitnessPal, LoseIt alternatives).
- **Legal:** src/pages/legal (Privacy, Terms).
- **Styles:** src/styles/main.css (Tailwind tokens).
