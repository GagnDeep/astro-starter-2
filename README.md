# CablePassport.com

The pragmatic, regulation-focused compliance platform specifically for the cable manufacturing and import industry to meet EU Ecodesign for Sustainable Products Regulation (ESPR) rules.

## Overview
This repository contains the Astro-based static site for CablePassport.com. It is built with Tailwind CSS v4 and integrates with a secure form capture API for lead generation.

## Key Features
- **Compliance Tools:** Includes a Compliance Checker, Data Requirements generator, and Carbon Estimator.
- **Reference Library:** Deep-dives into ESPR mandates for cables.
- **Implementation Guides:** Tactical steps for setting up a DPP.
- **Glossary:** Definitions for LCA, ESPR, DPP, and more.
- **Blog:** In-depth posts analyzing current market trends and regulations.
- **No-JS Support:** Forms and tools include robust no-JS fallbacks.
