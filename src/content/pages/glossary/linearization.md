    <h1 class="mt-8">Linearization</h1>

    <div class="bg-surface p-6 rounded-lg border-l-4 border-primary text-xl font-medium mb-8">
      Also known as Fast Web View. A specific organization of a PDF file that allows for the display of the first page before the entire file is downloaded.
    </div>

    <h2>Relevance to Document Viewers</h2>
    <p>Understanding <strong>Linearization</strong> is critical when building or integrating document viewing tools on the web. A misconfiguration can lead to poor performance, broken cross-browser rendering, or security vulnerabilities.</p>
