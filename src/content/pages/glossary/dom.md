    <h1 class="mt-8">DOM</h1>

    <div class="bg-surface p-6 rounded-lg border-l-4 border-primary text-xl font-medium mb-8">
      Document Object Model. A cross-platform and language-independent interface that treats an XML or HTML document as a tree structure.
    </div>

    <h2>Relevance to Document Viewers</h2>
    <p>Understanding <strong>DOM</strong> is critical when building or integrating document viewing tools on the web. A misconfiguration can lead to poor performance, broken cross-browser rendering, or security vulnerabilities.</p>
