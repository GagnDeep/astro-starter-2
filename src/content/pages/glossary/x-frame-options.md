    <h1 class="mt-8">X-Frame-Options</h1>

    <div class="bg-surface p-6 rounded-lg border-l-4 border-primary text-xl font-medium mb-8">
      An HTTP response header used to indicate whether or not a browser should be allowed to render a page in a `&lt;frame&gt;`, `&lt;iframe&gt;`, `&lt;embed&gt;` or `&lt;object&gt;`.
    </div>

    <h2>Relevance to Document Viewers</h2>
    <p>Understanding <strong>X-Frame-Options</strong> is critical when building or integrating document viewing tools on the web. A misconfiguration can lead to poor performance, broken cross-browser rendering, or security vulnerabilities.</p>
