    <h1 class="mt-8">Content Security Policy</h1>

    <div class="bg-surface p-6 rounded-lg border-l-4 border-primary text-xl font-medium mb-8">
      An added layer of security that helps to detect and mitigate certain types of attacks, including XSS and data injection.
    </div>

    <h2>Relevance to Document Viewers</h2>
    <p>Understanding <strong>Content Security Policy</strong> is critical when building or integrating document viewing tools on the web. A misconfiguration can lead to poor performance, broken cross-browser rendering, or security vulnerabilities.</p>
