    <h1 class="mt-8">WebAssembly (Wasm)</h1>

    <div class="bg-surface p-6 rounded-lg border-l-4 border-primary text-xl font-medium mb-8">
      A binary instruction format for a stack-based virtual machine, often used to run complex document parsers (like PDF engines) in the browser.
    </div>

    <h2>Relevance to Document Viewers</h2>
    <p>Understanding <strong>WebAssembly (Wasm)</strong> is critical when building or integrating document viewing tools on the web. A misconfiguration can lead to poor performance, broken cross-browser rendering, or security vulnerabilities.</p>
