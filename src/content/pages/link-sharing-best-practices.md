# Complete Guide to link sharing best practices

This page covers everything you need to know about link sharing best practices. It includes edge cases, worked examples, and actionable next steps.

## Understanding the Basics

When dealing with document previews, link sharing best practices is a common challenge. Unlike traditional downloads, in-browser rendering requires careful management of resources.

## Edge Cases and Exceptions

- **Large Files:** Files over 50MB may experience degraded performance.
- **Custom Fonts:** If a document uses non-standard fonts, they will fallback to system defaults.

## What to Do Next

1. Review your current document sharing workflow.
2. Utilize our format support checker.
3. Consider setting up expiration dates on sensitive links.
