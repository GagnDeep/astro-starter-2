# Complete Guide to security and privacy

This page covers everything you need to know about security and privacy. It includes edge cases, worked examples, and actionable next steps.

## Understanding the Basics

When dealing with document previews, security and privacy is a common challenge. Unlike traditional downloads, in-browser rendering requires careful management of resources.

## Edge Cases and Exceptions

- **Large Files:** Files over 50MB may experience degraded performance.
- **Custom Fonts:** If a document uses non-standard fonts, they will fallback to system defaults.
