# What is RTF?

Rich Text Format. A cross-platform document format developed by Microsoft in 1987 to allow basic formatting exchange between different word processors.

## Technical Architecture

The RTF format was engineered to solve specific data structuring and delivery problems in computing. Unlike plain text, complex formats require parser software to interpret the byte stream or XML structure.

## Primary Use Cases

*   **Delivery vs Editing:** Formats are generally split between final delivery (like PDF) and active editing (like DOCX).
*   **Web vs Print:** Image formats are divided into lossy (web-optimized) and lossless (archival or print-ready).
