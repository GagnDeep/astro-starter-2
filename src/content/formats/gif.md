# What is GIF?

Graphics Interchange Format. A legacy 8-bit image format supporting simple animations and lossless compression for basic graphics.

## Technical Architecture

The GIF format was engineered to solve specific data structuring and delivery problems in computing. Unlike plain text, complex formats require parser software to interpret the byte stream or XML structure.

## Primary Use Cases

*   **Delivery vs Editing:** Formats are generally split between final delivery (like PDF) and active editing (like DOCX).
*   **Web vs Print:** Image formats are divided into lossy (web-optimized) and lossless (archival or print-ready).
