# What is PDF?

Portable Document Format, created by Adobe in 1993, is the global standard for document delivery. It uses a PostScript-based absolute positioning layout.

## Technical Architecture

The PDF format was engineered to solve specific data structuring and delivery problems in computing. Unlike plain text, complex formats require parser software to interpret the byte stream or XML structure.

## Primary Use Cases

*   **Delivery vs Editing:** Formats are generally split between final delivery (like PDF) and active editing (like DOCX).
*   **Web vs Print:** Image formats are divided into lossy (web-optimized) and lossless (archival or print-ready).
