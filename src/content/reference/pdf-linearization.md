      <h1>PDF Linearization</h1>
      <p class="text-xl text-text/80">Fast web view optimization for PDFs.</p>

      <div class="mt-8">
        Linearization (or Fast Web View) restructures a PDF file so that the first page can be displayed before the entire file is downloaded. This is critical for large documents on slow mobile connections.
      </div>
