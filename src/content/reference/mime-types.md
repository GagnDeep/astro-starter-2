      <h1>MIME Types</h1>
      <p class="text-xl text-text/80">Complete list of document MIME types.</p>

      <div class="mt-8">
        Setting the correct `Content-Type` header is vital. PDFs must be `application/pdf`. Word documents (DOCX) are `application/vnd.openxmlformats-officedocument.wordprocessingml.document`. Incorrect MIME types will cause browsers to download the file instead of rendering it.
      </div>
