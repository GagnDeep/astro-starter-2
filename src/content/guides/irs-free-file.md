# IRS Free File

The IRS Free File program is the single most important tool for taxpayers looking to avoid predatory software fees.

## Overview
IRS Free File is a public-private partnership between the IRS and many tax preparation and filing software industry companies (the Free File Alliance). These companies provide their brand-name products for **free** to taxpayers whose Adjusted Gross Income (AGI) is below a certain threshold.

### Key Facts and Figures (2024 Filing Season)
- **AGI Limit:** $79,000 for the 2023 tax year (filed in 2024). *Note: This number typically adjusts slightly each year for inflation. Check IRS.gov for the exact 2024 limit when announced.*
- **Scope:** If you qualify, the software covers **all** tax forms. This means if you have a [1099-NEC](/guides/1099-nec-vs-1099-misc/), Capital Gains, or self-employment income, the software cannot upcharge you.
- **State Filing:** Some partners include free state filing, while others do not. You must read the partner's offer carefully.

### Worked Example: Beating the System
John has an AGI of $60,000. He works a W-2 job and has a small freelance business.
1. **The Wrong Way:** John goes to turbotax.com, clicks "Free Edition," enters his W-2, then enters his 1099. TurboTax forces him to upgrade to "Self-Employed" for $120.
2. **The Right Way:** John goes to IRS.gov, clicks on "Free File," selects the TurboTax (or TaxAct, or TaxSlayer) Free File offer. He creates a specific Free File account. He enters his W-2 and his 1099. **His cost is $0.**

### Edge Cases
- **Over the Limit:** If your AGI is over the limit, you can use IRS Free File Fillable Forms (electronic versions of IRS paper forms), but it provides minimal guidance and no math checking. We recommend looking at our [Which Free Tax Software is Best](/blog/which-free-tax-software-is-best) guide for alternatives like FreeTaxUSA.
- **Active Military:** Often, the AGI limits are waived or increased for active-duty military personnel.

### Common Mistakes
- **Googling "Free File":** Searching for free file often leads to the commercial "Free Editions" which are designed to upsell you. You *must* start from the IRS.gov link to ensure you are in the Free File program.
- **Using an existing account:** If you already started a return on a paid tier, you usually have to clear your return and start over through the IRS link to get the truly free version.
