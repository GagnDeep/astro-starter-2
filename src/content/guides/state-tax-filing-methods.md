# State Tax Filing Methods

Filing your federal return for free is one thing, but how do you file state taxes without paying a software upsell?

## Overview
State tax filing varies drastically depending on where you live. Some states have no income tax (like Texas and Florida), while others have complex systems.

### Direct File Options
Many states are rolling out their own direct file portals where you can submit your return directly to the state Department of Revenue for free. Additionally, the IRS Direct File pilot program in 2024 integrated with select state portals.

### The Software Upsell
A common tactic used by "Free Editions" of commercial software is to offer free federal filing but charge $40 or more for the state return.
* Solution 1: Use an [IRS Free File](/guides/irs-free-file/) partner that includes free state filing for your specific state.
* Solution 2: File your federal return for free, print it out, and then manually input those numbers into your state's free direct file portal.
