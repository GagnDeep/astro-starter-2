# What Is Epub Format

EPUB (Electronic Publication) is the standard for ebooks. Unlike PDF, EPUB is flowable—it adapts to the screen size. This guide covers the XML structure of an EPUB, how it compares to MOBI, and why converting PDF to EPUB requires heuristic layout analysis to determine where paragraphs end and pages begin.

## Understanding the Technical Landscape

When dealing with document conversion, you are essentially translating between different computing paradigms. As we discuss in our [difference between DOC and DOCX](/guides/difference-between-doc-and-docx) guide, modern formats utilize XML containers, while legacy formats or final delivery formats like PDF use absolute positioning.

### Common Challenges

The most frequent issue users encounter is format breaking. This happens because the source and destination formats do not share a 1:1 mapping of features.

> "The fundamental problem of document interoperability is that every format was designed to solve a different problem at a different time in computing history."
