Reading academic papers is fundamentally different from reading a textbook. Papers are dense, jargon-heavy, and require active engagement. Here is a systematic workflow for annotating PDFs in college.

## 1. The Color Code System

Don't just paint the page yellow. Develop a system. For example, using our [Annotation Tool](/tools/annotate-pdf):
*   **Yellow Highlight:** Main arguments and thesis statements.
*   **Green Highlight:** Important methodology details or data points.
*   **Red Strikeout:** Counterarguments the author refutes.
*   **Blue Text Notes:** Your own questions or synthesis connecting to other papers.

## 2. First Pass vs. Second Pass

Never highlight on your first read. Read a section, understand the core concept, and then go back and highlight only the most critical sentences.

## 3. Dealing with Scanned Documents

Many older papers provided by university libraries are just image scans. You won't be able to select the text to highlight it cleanly. In these cases, you must use a freehand drawing tool to underline, or run the file through OCR software first.
