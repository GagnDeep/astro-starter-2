# A Quick Guide to Document Accessibility

Creating documents that everyone can read is not just a best practice; in many industries, it's a legal requirement.

## Key Principles

### 1. Semantic Structure

Always use proper heading tags (H1, H2, H3) rather than just making text bold and large. Screen readers rely on this structure to navigate the document.

### 2. Alt Text for Images

Every informative image must have alternative text describing its content. If an image is purely decorative, it should be marked as such so screen readers ignore it.

### 3. Color Contrast

Ensure sufficient contrast between text and background colors. Avoid relying solely on color to convey meaning (e.g., "click the red button").
