# Encryption

**Definition:** The process of encoding a message or document (like a secure PDF) so that only authorized parties can access it.

## Technical Context

Understanding encryption is essential for proper document conversion and handling. It directly impacts how data is processed, stored, and displayed on screen versus in print.
