# Lossy

**Definition:** A compression method that discards some data to achieve smaller file sizes, commonly used for JPEG images.

## Technical Context

Understanding lossy is essential for proper document conversion and handling. It directly impacts how data is processed, stored, and displayed on screen versus in print.
