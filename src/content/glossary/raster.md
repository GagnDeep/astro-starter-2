# Raster

**Definition:** A dot matrix data structure representing a generally rectangular grid of pixels, or points of color (like a photograph).

## Technical Context

Understanding raster is essential for proper document conversion and handling. It directly impacts how data is processed, stored, and displayed on screen versus in print.
