# Dpi

**Definition:** Dots Per Inch. A measure of spatial printing or video dot density, heavily impacting file size during conversion.

## Technical Context

Understanding dpi is essential for proper document conversion and handling. It directly impacts how data is processed, stored, and displayed on screen versus in print.
