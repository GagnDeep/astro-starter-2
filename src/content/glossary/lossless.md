# Lossless

**Definition:** A class of data compression algorithms that allows the original data to be perfectly reconstructed from the compressed data.

## Technical Context

Understanding lossless is essential for proper document conversion and handling. It directly impacts how data is processed, stored, and displayed on screen versus in print.
