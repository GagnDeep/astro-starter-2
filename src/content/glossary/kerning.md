# Kerning

**Definition:** The process of adjusting the spacing between characters in a proportional font to achieve a pleasing result.

## Technical Context

Understanding kerning is essential for proper document conversion and handling. It directly impacts how data is processed, stored, and displayed on screen versus in print.
