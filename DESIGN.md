# Design Direction

**Art Direction:** Technical-brutalist (stark, utilitarian, code-first).

**Palette (OKLCH):**
- **Brand Hue (Cyan/Blue - from IDE interface highlights):** `oklch(60% 0.15 250)`
- **Supporting Hue (Purple/Indigo - from API terminal outputs):** `oklch(55% 0.15 285)`
- **Neutral Ramp (Titanium/Dark Mode Surface - from Server Racks):** `oklch(20% 0.02 260)` to `oklch(95% 0.01 260)` (Chroma 0.01-0.03)

**Typography:**
- **Headings & Display:** Geist (Self-hosted)
- **Body & Code:** Geist Mono (Self-hosted)
