# Design System

**Art Direction:** Editorial/Swiss

**Palette:**
- Base: Financial broadsheet paper (warm off-white/cream) -> Lightness: 0.98, Chroma: 0.01, Hue: 85 (OKLCH).
- Brand Hue: Institutional navy ink -> Lightness: 0.35, Chroma: 0.08, Hue: 260.
- Supporting Hue: Charted red (for critical/loss indicators) -> Lightness: 0.50, Chroma: 0.15, Hue: 30.

**Typography:**
- Two self-hosted fonts.
- Display: Playfair Display (or similar high-contrast serif).
- Body: Work Sans (or similar legible sans-serif for dense data).
